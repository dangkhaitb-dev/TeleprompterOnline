# Project instructions

## Frontend and responsive design

- Build every page mobile-first. Base styles must target small screens first; add layout complexity with `min-width` media queries.
- Support at least 320px, 390px, 768px, 1024px, and 1440px viewport widths.
- Never ship horizontal page overflow. Images, tables, grids, controls, and long text must remain usable within the viewport.
- On mobile, prioritize the reading order: section heading, primary product visual, supporting content, then secondary details.
- Do not force unequal content blocks into equal-height side-by-side cards. Stack them sequentially on small screens and use asymmetric layouts only when space permits.
- Keep touch targets at least 44px where practical and preserve visible keyboard focus states.
- Use the existing system font stack. Do not add external web fonts unless the user explicitly requests one.
- Before finishing visual work, verify the whole affected page on mobile, tablet, and desktop—not only the edited section.
